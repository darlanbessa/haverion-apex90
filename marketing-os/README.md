# Marketing OS — Pacote Completo para Codex

Sistema de agentes especializados para operação de marketing digital com contexto compartilhado, fluxo coordenado por um agente Maestro e memória operacional versionada no GitHub.

## Objetivo
Montar uma operação de marketing altamente automatizada, com tarefas padronizadas e revisão humana nos pontos críticos.

## Princípios
- automação alta
- contexto forte
- tarefas padronizadas
- integração com GitHub
- revisão humana nos pontos críticos

## Arquitetura de agentes
- Agent 0 — Maestro
- Agent 1 — Estratégia
- Agent 2 — Copy
- Agent 3 — VSL
- Agent 4 — Criativos
- Agent 5 — Imagens Ultra Realistas
- Agent 6 — Vídeos
- Agent 7 — Anúncios
- Agent 8 — Meta Ads
- Agent 9 — Analytics / Otimização
- Agent 10 — Funil / Automação
- Agent 11 — GitHub Ops / Memória Operacional

## Fluxo base
1. Maestro recebe objetivo
2. Estratégia define base de campanha
3. Copy cria peças persuasivas
4. Criativos/Imagens/Vídeos produzem ativos
5. Anúncios e Meta Ads estruturam mídia
6. Funil define automação e conversão
7. Analytics otimiza
8. GitHub Ops registra aprendizado

Use o conteúdo de `01_maestro/maestro.md` junto com o contexto em `00_contexto/contexto_base.md`.
